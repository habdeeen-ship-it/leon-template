# Leon Agency - Landing Page

## المشروع / Project

**العربية:** صفحة هبوط (Landing Page) لوكالة تصميم وتطوير مواقع، مبنية بالكامل باستخدام HTML5 و CSS3 بدون أي مكتبات أو أطر عمل خارجية، وهي مأخوذة عن قالب "Leon Agency Template".

**English:** A landing page for a web design and development agency, built entirely with HTML5 and CSS3 without any external frameworks. It is based on the "Leon Agency Template".

---

## التقنيات المستخدمة / Technologies Used

- HTML5 (semantic elements)
- CSS3 (CSS Variables, Flexbox, Grid, Media Queries, `calc()`)
- Font Awesome (icons via CDN)
- Google Fonts (Work Sans)

---

## خطوات التشغيل / How to Run

**العربية:**
1. حمّل المشروع أو انسخه من GitHub.
2. ضع الصور المطلوبة داخل مجلد `images/` بالأسماء الموضحة أعلاه.
3. افتح ملف `index.html` في المتصفح مباشرة.

**English:**
1. Download or clone the project from GitHub.
2. Put the required images inside the `images/` folder using the names listed above.
3. Open `index.html` directly in your browser.
